# 🌟 EnglishLearning - Nền Tảng Học Tiếng Anh Trực Tuyến

EnglishLearning là một ứng dụng web học tiếng Anh toàn diện được xây dựng bằng ASP.NET Core MVC. Hệ thống cung cấp đa dạng các bài học, khoá học, từ điển, bài tập ngữ pháp, luyện thi TOEIC và quản lý tiến độ học tập cho người dùng, đi kèm với một trang quản trị (Admin Panel) riêng biệt giúp hệ thống hoạt động ổn định và có thể tùy chỉnh dễ dàng.

## ✨ Tính Năng Nổi Bật

### 🧑‍🎓 Dành cho Người dùng (User)
- **Xác thực & Bảo mật (Authentication)**: 
  - Đăng ký, Đăng nhập với tài khoản ứng dụng.
  - Hỗ trợ đăng nhập nhanh qua **Google** và **Facebook**.
  - Quản lý hồ sơ cá nhân và đổi mật khẩu.
- **Khóa học & Bài học (Courses & Lessons)**: 
  - Xem danh sách các khóa học và bài học theo từng cấp độ (Learning Level, Sub Level).
  - Trải nghiệm bài học đa phương tiện (Video, Audio, Hình ảnh).
  - Luyện thi TOEIC chi tiết chia theo từng phần (Part 1, Part 2,..., Part 7).
- **Từ điển & Dịch thuật (Dictionary & Translation)**:
  - Tra cứu từ vựng trực tuyến nhanh chóng.
  - Dịch văn bản và lưu trữ lại danh sách lịch sử dịch thuật (Translation History).
- **Flashcard (Thẻ ghi nhớ từ vựng)**:
  - Cho phép tạo các bộ Flashcard (Flashcard Set) theo chủ đề cá nhân.
  - Thêm, sửa, xóa từng thẻ chữ (Flashcards).
  - Giao diện ôn tập (Study) trực quan để ghi nhớ từ vựng hiệu quả nhờ sự lặp lại.
- **Kiểm tra Ngữ pháp (Grammar)**:
  - Hỗ trợ kiểm tra cấu trúc câu, check ngữ pháp văn bản tiếng Anh tự động.
- **Trắc nghiệm & Bài Kiểm Tra (Quiz & Test)**:
  - Làm bài trắc nghiệm (Quiz) để ôn tập và củng cố kiến thức nhanh.
  - Tham gia làm bài kiểm tra (Test) mô phỏng các kỳ thi hoặc bài đánh giá năng lực thực tế.
- **Theo dõi Tiến độ (Progress Tracking)**: 
  - Ghi nhận, lưu trữ và hiển thị tiến độ học tập, thành tích điểm số bài thi của từng học viên.

### 👨‍💻 Dành cho Quản trị viên (Admin)
Hệ thống Admin được tách route phân quyền riêng biệt tại cổng `/Admin/Auth/Login` với quyền hạn đầy đủ:
- **Quản lý Tài khoản (User Management)**: 
  - Xem danh sách, tìm kiếm, khóa (ban), mở khóa hoặc thay đổi quyền hạn người dùng.
- **Quản lý Nội dung học (Content Management)**:
  - Quản lý Khóa học (Courses): Thêm, sửa định dạng khóa học.
  - Quản lý Bài học (Lessons): Soạn thảo bài học, hỗ trợ upload ảnh, video, thẻ giải thích TOEIC đa dạng (hệ thống cho phép upload file bài học lên đến 200MB).
  - Quản trị kho từ vựng và Flashcards của hệ thống.
- **Quản lý Bài thi & Quiz**: Cấu hình các bộ câu hỏi, kỳ thi thử TOEIC cũng như các bài tập luyện tập nhỏ.
- **Thống kê & Giám sát**:
  - Xem tổng quan về dữ liệu hệ thống và hoạt động của người dùng trên nền tảng.

## 🚀 Công Nghệ Sử Dụng (Tech Stack)

- **Backend Platform**: C# với framework ASP.NET Core MVC.
- **Cơ sở dữ liệu**: SQL Server thực thi qua Entity Framework Core (Tiếp cận theo mô hình Code-First / Migrations).
- **Frontend App**: HTML5, Vanilla CSS / Bootstrap, JavaScript tương thích giao diện học tập đa thiết bị, triển khai qua Razor Views (.cshtml).
- **Security & Authentication**: ASP.NET Core Identity Cookies Authentication, Google OAuth, Facebook OAuth.

## 🛠 Hướng Dẫn Cài Đặt và Chạy Dự Án

### Yêu cầu hệ thống:
- [Visual Studio 2022](https://visualstudio.microsoft.com/) (Khuyên dùng) hoặc VS Code đi kèm thư viện .NET.
- [.NET SDK 6.0 trở lên](https://dotnet.microsoft.com/download) tùy môi trường đích.
- Hệ quản trị CSDL [SQL Server](https://www.microsoft.com/en-us/sql-server/sql-server-downloads).

### Các bước cài đặt:

1. **Tải mã nguồn về máy**:
   Mở thư mục chứa mã nguồn hoặc Clone dự án từ kho lưu trữ.

2. **Mở dự án trên IDE Visual Studio**:
   - Khởi chạy file giải pháp trung tâm: `EnglishLearning.sln`.

3. **Cấu hình chuỗi kết nối (Database Connection String)**:
   - Trong thư mục project `EnglishLearning`, tìm mở file `appsettings.json` (hoặc `appsettings.Development.json`).
   - Cấu hình chuỗi kết nối `DefaultConnection` cho phù hợp với thông tin kết nối SQL Server local của bạn. 
     *Ví dụ mẫu:*
     ```json
     "ConnectionStrings": {
       "DefaultConnection": "Server=.\\SQLEXPRESS;Database=EnglishLearningDB;Trusted_Connection=True;MultipleActiveResultSets=true;Encrypt=False"
     }
     ```

4. **Cấu hình Social Login: Google / Facebook (Tùy chọn bổ sung)**:
   - Trong `appsettings.json`, bên dưới node `Authentication`: cung cấp `ClientId` và `ClientSecret` của Google & Facebook để bật khả năng tích hợp mạng xã hội. (Có thể tham khảo cấu trúc tại `appsettings.example.json` nếu có).

5. **Sinh Cấu trúc Cơ sở dữ liệu (Database Migration)**:
   - Mở **Package Manager Console** trong Visual Studio (`Tools` -> `NuGet Package Manager` -> `Package Manager Console`).
   - Đảm bảo tham số `Default project` là `EnglishLearning`.
   - Thực thi lệnh sau để cập nhật Database, tạo bảng và các quy tắc:
     ```powershell
     Update-Database
     ```

6. **Chạy ứng dụng**:
   - Nhấn phím `F5` hoặc nhấn nút **IIS Express / http** phía trên thanh công cụ của Visual Studio.
   - Trình duyệt sẽ tự động mở trang chủ (Thường ở `https://localhost:xxxx`).

### 🐳 Triển khai với Docker (Tùy chọn)

Nếu bạn muốn chạy dự án thông qua Docker để đảm bảo môi trường hoạt động nhất quán mà không cần cài đặt .NET SDK hay SQL Server cục bộ:

1. **Chuẩn bị môi trường**: Đảm bảo máy tính của bạn đã cài đặt [Docker Desktop](https://www.docker.com/products/docker-desktop).

2. **Build Image và Run Container (Bằng Docker CLI)**:
   Mở terminal tại thư mục chứa file `Dockerfile` và chạy lệnh sau để build image:
   ```bash
   docker build -t englishlearning-app .
   ```
   Sau khi build xong, khởi chạy container:
   ```bash
   docker run -d -p 5000:5000 -p 5001:5001 --name el-app englishlearning-app
   ```
   Truy cập ứng dụng trên trình duyệt tại: `http://localhost:5000` hoặc `http://localhost:5001`.

3. **Sử dụng Docker Compose (Khuyên dùng)**:
   Nếu dự án đi kèm file `docker-compose.yml` (để tự động liên kết ứng dụng và CSDL SQL Server trong container), bạn chỉ cần mở terminal ở thư mục gốc và chạy lệnh:
   ```bash
   docker-compose up -d
   ```
   Hệ thống sẽ tự động tải image cần thiết, chạy cả ứng dụng và cơ sở dữ liệu. Để dừng hệ thống, sử dụng lệnh:
   ```bash
   docker-compose down
   ```

## 📚 Hướng Dẫn Sử Dụng Cơ Bản

### Đối với Người học (User):
1. **Truy cập nền tảng**: Người học ghé trang chủ của ứng dụng web.
2. **Đăng nhập hoặc Đăng ký**: Chọn mục Login. Người dùng có thể tạo một tài khoản điền thông tin mới chuyên nghiệp hoặc đăng nhập cực kì nhanh chóng trích xuất hồ sơ bằng nút của Google/Facebook.
3. **Bắt đầu trải nghiệm học tập**: Giao diện chính liệt kê các tính năng qua menu dẫn hướng bao gồm: 
   - Đăng ký và tham gia các **Khóa học (Courses)**.
   - Truy xuất công cụ **Tra từ điển, Check ngữ pháp** hỗ trợ việc hiểu đoạn trích.
   - Tự soạn **Flashcard** để lật mở, học từ vựng hiệu quả mỗi ngày.
   - Tham gia thi thử TOEIC mô phỏng và **Bài kiểm tra (Test/Quiz)**. 
   - Hệ thống tự chủ động tính điểm và lưu trữ vào phần **Tiến độ học tập** của học viên.

### Đối với Quản trị viên (Admin):
1. **Thiết lập quyền Admin**: Bạn cần một tài khoản có Role là Admin.
   > *(Mẹo: Hãy tham khảo file `ADMIN_LOGIN_GUIDE.md` đính kèm trong thư mục hoặc tự cập nhật trong SQL Server bảng `User` để xem/cấp tài khoản Admin).*
2. **Khu vực đăng nhập chuyên trách**: Vui lòng truy cập thông qua trình duyệt vào URL: `{domain-chạy-web}/Admin/Auth/Login` để đăng nhập vào trang chủ quản trị.
3. **Quản lý dữ liệu**: Sử dụng thanh Sidebar bên trái Dashboard của Admin. Từ đó, ban quản trị được phép thao tác toàn quyền hệ sinh thái bao gồm quản lý list Học viên, Nội dung phân bổ của Hệ thống, duyệt các bộ thẻ Flashcard của hệ thống.
4. **Hỗ trợ Media nội dung**: Ở kho quản lý "Bài học", Admin dễ dàng upload các tệp lớn chứa nội dung nghe (Audio), đoạn phim tình huống (Video) hoặc ảnh chụp nội dung với trần giới hạn băng thông upload được cấp lên rất cao (đến 200MB theo cấu hình hệ thống).
